# TokenPilot 0.1.0-alpha.1

TokenPilot is a ChatGPT-first dual-mode development workflow: GPT direct-drive for frequent small changes, and Codex async runs for complex repository work.

This is a GitHub prerelease source preview for developers evaluating the local-first workflow. It is not an npm package, native installer, public SaaS service, or production-grade multi-runner platform.

This prerelease has been repacked after the source-archive smoke repair: GitHub automatic source archives and the curated `tokenpilot-source` archive are expected to work from a fresh extraction that does not contain a `.git` directory.

## Positioning

- ChatGPT acts as the brain and command center for context management, planning, orchestration, and review.
- TokenPilot provides the local-first control plane for task boundaries, mode routing, persistent state, and public-safe artifacts.
- GPT direct-drive covers frequent small edits, short checks, and public-safe Git operations.
- Codex async runs cover complex repository work with queued jobs, optional worktrees, diffs, artifacts, and review.

## Included

- Local CLI for `pack`, `manifest`, `taskpack`, queue, job, server, and runner workflows.
- Fastify control plane with OpenAPI for Custom GPT Actions experiments.
- File-backed local job queue for pack, taskpack, and Codex-run jobs.
- Files API for read/write/edit flows with public-safe path filtering.
- Code search, allowlisted short shell checks, and Git status/diff/commit APIs.
- `createCodexRun` jobs executed by the local runner and Codex CLI.
- Local operator Web UI for status, jobs, GPT helper instructions, artifacts, and controlled job process actions.
- Exposed mode with bearer auth before private job APIs can be used over HTTP.
- TokenPilot internal XML bundle generator, replacing the previous hard Repomix dependency while keeping the `repomix-output-*.xml` compatibility path.
- Current-tree and Git history privacy scanning helpers.
- Bilingual README and dual-language hero assets.
- First-run setup wizard and one-command local runtime aliases.
- Beginner quickstart, Custom GPT / GPT Builder setup, and public HTTPS / tunnel setup docs.
- Chinese-first documentation map from the default README, with English docs available through `README.en.md`.

## Security And Privacy

- Exposed-mode write APIs require bearer auth.
- `runShell` is allowlisted and bounded, but remains a high-trust local operator API.
- Public API responses, diffs, commits, and Codex artifacts are filtered to avoid local absolute paths and runtime state leakage.
- The release dry-run builds from a Git-tracked source archive and rejects local runtime paths, env files, build outputs, and ignored machine state.
- Source archive verification no longer initializes a hidden `.git` directory before smoke tests.
- Required release gates include `npm audit --audit-level=moderate`, `npm run privacy:scan:history`, `npm run verify`, and `npm run verify:release`.

## Known Limitations

- Full HTTPS / Custom GPT Actions end-to-end production loop is still under validation.
- The Web UI is a local operator console, not a public management platform.
- Provider adapters beyond Codex are not yet included.
- Storage layout, job artifacts, and local runtime contracts may change during alpha.
- Source preview only: no npm publish, no native installer, and no hosted service.

## Upgrade Notes

The pack flow now uses TokenPilot's internal XML bundle generator. The compatibility artifact path and artifact key remain `repomix-output-*.xml` and `repomixXml`, but the `repomix` npm package is no longer required.

The repacked `v0.1.0-alpha.1` source preview also includes the no-`.git` release smoke fix, Chinese documentation map repair, GPT Builder setup docs, and public HTTPS / tunnel setup docs.
